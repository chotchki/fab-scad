## TB. macOS auto-update: releases that install themselves

- [x] TB.1 Decide the mechanism: cargo-packager-updater vs hand-rolled GitHub-API check — pin versions, macOS bundle-replace caveats (translocation, quarantine, relaunch). SETTLED (research workflow, 4 agents on the 0.2.3/0.11.8 SOURCE): cargo-packager-updater 0.2.3 — co-released with the cargo-packager 0.11.8 we already run, and the artifacts are nearly free (setting CARGO_PACKAGER_SIGN_PRIVATE_KEY makes sign_outputs tar the STAPLED .app + minisign it; ordering verified). Endpoint = static latest.json on releases/latest/download (plain web redirect, no API rate limits). Three landmines the research paid for: the platform key is macos-aarch64 (the crate's OWN docs say darwin-* and its code can never match that), CI must author latest.json itself (upstream #350), and macOS relaunch is the caller's job. Hand-rolling would have re-derived all of this with none of the tauri-lineage maturity.
- [x] TB.2 Release side: updater artifact + signed update manifest on every v* tag; key ceremony documented in docs/packaging.md. Keypair MINTED 2026-08-11 (passwordless, ~/.config/fab-scad/update-signing.key, pubkey baked into gui/src/update.rs); the one human step left is `gh secret set CARGO_PACKAGER_SIGN_PRIVATE_KEY` (classifier blocked the agent doing it) + password-manager backup. Secrets-gated like Apple signing; cargo-packager now PINNED to 0.11.8 (tar layout + sig format are a shipped contract with installed apps).
- [x] TB.3 App side: launch check + egui dialog with install-and-relaunch; manual check button in Settings; FAB_UPDATE_CHECK=off opt-out. AMENDED from "throttled + settings opt-out": no throttle (one unauthenticated web GET per windowed launch needs none, and a throttle would have forced a persisted-state file) and env-var opt-out (the only settings file today is the 0600 credentials.toml — updater prefs don't belong in a secrets file; a real settings.toml is deferred until a second consumer shows up). Launch check reports NOTHING on failure (a mid-upload release 404s like "no update"); only the manual path nags. Packaged-bundle detection gates the check; translocation detected up front in the dialog.
